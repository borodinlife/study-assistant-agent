# Помощник по учёбе (`study-assistant-agent`)

## Назначение агента
Консольное приложение для учёта учебных заданий студента. Программа позволяет добавлять лабораторные, курсовые и домашние работы по дисциплинам, просматривать общий список задач или фильтровать их по предмету, отмечать выполнение работ и удалять неактуальные записи.

## Технологический стек
- **Редактор кода / IDE:** Visual Studio Code
- **Язык программирования и версия:** `Python 3.15.1`
- **Среда выполнения:** интерпретатор `CPython`, изолированное виртуальное окружение `venv` (`.venv`)
- **Менеджер зависимостей:** `pip` (зависимости зафиксированы в файле `requirements.txt`)
- **Используемые библиотеки:** стандартная библиотека Python (`json`, `os`)
- **Средства хранения данных:** оперативная память (`list[dict]`) с автоматическим сохранением состояния в локальный файл формата `JSON` (`tasks.json`)
- **Отладчик:** встроенный отладчик VS Code для Python (`debugpy` / `pdb`)
- **Линтер:** `Ruff` (`ruff check`)
- **Форматтер:** `Ruff` (`ruff format`)

## Структура проекта
- `main.py` — точка входа в приложение: цикл чтения команд, разбор аргументов, валидация пользовательского ввода и вывод данных в консоль.
- `tasks.py` — модуль операций с данными: загрузка и сохранение состояния в `tasks.json`, функции добавления, фильтрации, отметки выполнения и удаления заданий.
- `requirements.txt` — список зависимостей проекта для воспроизводимой установки окружения.
- `.gitignore` — список исключений Git (виртуальное окружение `.venv`, кэш `__pycache__`, локальный файл базы `tasks.json`).

## Подготовка окружения и запуск

1. Клонировать репозиторий и перейти в каталог проекта:
   ~~~powershell
   git clone https://github.com/borodinlife/study-assistant-agent.git
   cd study-assistant-agent
   ~~~
2. Создать и активировать виртуальное окружение:
   ~~~powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ~~~
3. Установить зависимости из файла `requirements.txt`:
   ~~~powershell
   pip install -r requirements.txt
   ~~~
4. Запустить приложение:
   ~~~powershell
   python main.py
   ~~~

## Доступные команды и штатное завершение
- `add <предмет>; <название>; <срок>` — добавить новое учебное задание (аргументы разделяются точкой с запятой `;`).
- `list` — показать все сохранённые задания и их текущие статусы.
- `list <предмет>` — показать задания только по указанной дисциплине (без учёта регистра).
- `done <id>` — перевести задание с указанным числовым идентификатором в статус `выполнено`.
- `delete <id>` — удалить задание по его числовому идентификатору.
- `help` — вывести справочную информацию со списком команд и их назначением.
- `exit` — штатно завершить работу приложения (также поддерживается выход по сочетанию клавиш `Ctrl + C`).

## Способ хранения данных
Во время работы программы список заданий хранится в оперативной памяти в виде списка словарей (`list[dict]`). Каждое задание содержит поля `id`, `subject`, `title`, `deadline` и `status`. При запуске приложения функция `load_tasks()` считывает данные из файла `tasks.json` (если файл отсутствует или повреждён, создаётся пустой список). При каждом изменении состояния (`add`, `done`, `delete`) функция `save_tasks()` автоматически перезаписывает файл `tasks.json`, обеспечивая сохранность данных между запусками программы.

## Проверка качества кода (линтер и форматтер)
Для статического анализа и форматирования кода используется инструмент `Ruff`.

- Запуск линтера для проверки кода на ошибки и соответствие правилам стиля:
  ~~~powershell
  ruff check .
  ~~~
- Проверка соответствия кода правилам форматтера (без изменения файлов):
  ~~~powershell
  ruff format --check .
  ~~~
- Автоматическое форматирование кода проекта:
  ~~~powershell
  ruff format .
  ~~~

Список заданий:

Работа программы завершена.
