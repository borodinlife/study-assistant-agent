# Помощник по учёбе (`study-assistant-agent`)

## Назначение агента
ИИ-агент предназначен для учёта учебных заданий студента. Программа помогает распределять лабораторные, курсовые и домашние работы по дисциплинам, контролировать ближайшие сроки сдачи и отслеживать прогресс выполнения задач в течение семестра.

## Язык программирования
Для разработки выбран язык программирования `Python` (с использованием стандартной библиотеки и хранением данных в файле формата `JSON`).

## Планируемые возможности
- **Добавление заданий:** создание новой записи с указанием названия предмета, типа работы и крайнего срока сдачи.
- **Просмотр ближайших сроков:** вывод списка активных задач, отсортированных по дате сдачи, а также фильтрация заданий по конкретной дисциплине.
- **Отметка о выполнении:** перевод статуса выбранного задания из состояния `активно` в `выполнено` с сохранением задачи в архиве.
- **Удаление заданий:** удаление ошибочно созданных или отменённых работ из общего списка.
